# Phase tracker

`TASKS.md` is the CandyOS phase tracker — the project's working plan, QA
log, and decision record. It previously lived at `frameworks/base/TASKS.md`
in the old dev forks and was relocated here, unchanged, when the project
moved to the single-repo model (P1–P21 history references it by that path).

Commits referencing "frameworks/base/TASKS.md" or "TASKS.md Phase N" in
their messages refer to this file.

* Phases 1–20 are complete (their record lives in TASKS.md).
* Phase 21 (shade/QS rollback) is complete; the notification shade and
  quick settings intentionally stay stock LineageOS.
* Open phases (P16 Tier 2+ app ports, P11+ QA backlog, P24 device-install
  pass, ...) live in TASKS.md — pick one up, and record progress there as
  you go.
